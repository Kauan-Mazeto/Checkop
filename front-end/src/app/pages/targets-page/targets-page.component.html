Como protegemos sites de produção

  • Só o dono varre. Cada conta recebe um token próprio; a prova publicada vale só para quem a gerou.
  • Conferido sempre. A prova é checada ao criar e de novo a cada execução. Removeu o TXT, perdeu o acesso.
  • Ataque só com autorização. Em produção, a varredura ativa exige duas declarações a cada execução, registradas com data, hora e IP.
  • Sem derrubar o site. Ataques em produção rodam devagar e testes de negação de serviço nunca rodam.
  • Rede interna bloqueada. Domínio que aponta para IP interno é recusado.

Testar sistemas de terceiros sem autorização é crime (art. 154-A do Código Penal).
